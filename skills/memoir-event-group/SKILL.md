# Memoir Event Group

Run after timeline extraction inside the same leased publication step. The
timeline provides draft time bounds, location, exact evidence and any supported
candidate identity. A draft is private until the canonical event writer commits.

Group compatible drafts for the same scoped event and revision, retaining their
original evidence. An exact duplicate draft needs only one new event. Keep
different recollections separate even when they share a place and date. An
ambiguous match remains unresolved. Conflicting proposals for the same event
must be reconciled against the original before publication can continue.

Order by supported starts, ages and explicit chronology. Apply revisions and
remap the event/place links in the same transaction. A failed or stale page
leaves the last published events available. Explicit author overrides and
source withdrawal retain their existing authority.

The map groups the active published events by their public geography. A city
card spans the earliest known start and latest known end among its events.
Source-supported place cues for research are projected from the same events.
The host runs this step automatically and performs the writes. It requires no
extra model request.
