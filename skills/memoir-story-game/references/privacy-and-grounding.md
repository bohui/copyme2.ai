# Grounding and private playback

The host supplies permitted composer prose and canonical timeline records. Scene planning preserves chapter/event identities, source attribution, uncertain dates and supported chronology. Quotations must occur exactly in a supplied chapter block. Titles and optional represented-person labels occur inside their scene's quotation. A missing second person does not block a memory marker, and recurring people need not be disguised as different identities.

Keep the author's perspective. Interactions display memoir narration, not new testimony, invented personality, motives, diagnoses or independent judgments by another person. Sensitive or restricted material remains subject to the host's existing source-access rules. The skill cannot grant permissions or fabricate a review receipt.

The page builder receives the validated scene text, locale and public UI labels. It does not receive source IDs, canonical event IDs, chapter IDs, job tokens or authority metadata. Astra designs static HTML/CSS; the host inserts narrative text and trusted interaction behavior. Unrecognized factual page text and active/external content fail validation.

The host saves successful output for private workspace play. The owner confirms a scene subset against the current pool before brief composition or building. Adaptation consent cannot substitute for that choice. There is no additional publishing or person-permission review. Existing consent and source-revocation controls remain effective; public publication and sharing belong to separate host controls.
