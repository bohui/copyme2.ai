# Memoir game specification

Build a personal introduction as a playable side-scrolling journey through the author's memories. The player controls the author and moves between scenes, approaching characters or memory markers to explore the author's experiences.

The skill has exactly two steps:

1. Chapters from memoir-composer plus events from memoir-author-timeline become a source-linked scene plan. Preserve the selected stage/lifetime scope, supported chronology, uncertainty and attribution. Choose the scene count for the material, within the runtime's 128-scene bound.
2. Astra builds a responsive HTML/CSS webpage from the scene plan. Validate the result and use the host's movement/interaction engine. Give scenes distinct visual settings, smooth connected travel, keyboard/touch controls, readable dialogue, reduced-motion behavior and a complete text version.

Creative presentation is welcome; personal facts remain grounded in supplied chapters and timeline events. The generated page uses generic visual representations and the author's account rather than invented testimony from represented people.

The skill returns scenes and a playable webpage. Review and publication are not additional skill phases. The host saves successful output and presents it immediately for private play. Private workspace access does not imply a public website or authorize public sharing.
