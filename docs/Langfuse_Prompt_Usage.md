# Prompt-by-prompt usage audit

Verified against the Memoir repository and local Langfuse project on 18 October 2026. All 80 retained names match the registry and exact version receipts. This is execution-path evidence, not proof of recent production traffic.

## What is actually used

| Classification | Prompts | Meaning |
| --- | ---: | --- |
| Runtime | 20 | A current canonical application path submits the text, including individual components of its request. |
| Conditional runtime | 21 | A current path submits it only for the named feature, action, phase or locale. |
| Shared runtime | 10 | An actual runtime builder includes this source; it is not a second model invocation. |
| Evaluation only | 18 | An explicit evaluation command submits it; ordinary application requests do not. |
| Packaged skill only | 10 | Distributed/manual skill guidance. No app/evaluation model submission was found; do not call this production usage. |
| Compatibility only | 1 | An older compatibility/evaluation seam. Not part of the normal canonical workflow. |

The ten packaged entries are retained because the requested scope includes installed skill instructions and their referenced guides. Their presence in the app image, a link from SKILL.md, a cache fingerprint, and a model invocation are different evidence. They must not be reported as active runtime prompts.

## Execution paths and code changes

- The browser now sends original text. Its five discarded instruction templates and generated module were removed. `CodexRuntime.turn` already selects `conversation_text`, so those browser instructions never reached the governed model call.
- `run_lifetime_turn` selects one collector contract. Comfort/explore/shape are variants in that same foreground call, not three pipelines. They now read shared guidance/selection components.
- Both timeline contracts run through `_extract` / `lane_contract`. The derived variant adds fields when two-lane work is enabled. Both now read the same skill, service contract and grounding component.
- `compose_shared_snapshot` runs preparation, drafting and review over the canonical event/source index. Its draft and review share editorial components; this does not run timeline extraction again.
- Paid-book organiser leaf/merge jobs are bounded structural aggregation, not a second autobiographical event index. Their locale/phase policies now share components. `JobRequestBody` also now inherits the lane initializer: its duplicated setup had omitted `_after_send` and failed during HTTP transport.
- `composer/index` remains an explicit compatibility/benchmark exception: `index_sources` belongs to the older preview route. Normal canonical jobs bypass it, and `composer_call` blocks noncanonical model dispatch. This audit does not claim that path has production model traffic.

Runtime and dataset evaluation now use `apps/api/prompt_composition.py`. Each template contains component references; each component has one Langfuse source. The dataset preflight records every selected component version/hash plus the assembled SHA-256. `make prompt-check` validates both source pins and composition.

Fourteen refactored model inputs were compared byte-for-byte with their pre-refactor inputs. All matched. The change removes 57,061 copied source characters without changing these model inputs. This does not claim that semantically similar policy sentences never occur elsewhere.
