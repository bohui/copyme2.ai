# Accepted semantic checkpoints

Large histories now use the existing canonical checkpoint and timeline B owner
for resumable selective summaries. The earlier evidence under strategy-* stays
pinned to87478ec. All production/live-provider controls remain OFF.

The canonical ContextCheckpoint permits sixteen verbatim evidence windows.
A raw coverage hash and two excerpts cannot summarize an interval.
The same checkpoint now also accepts an explicit selective derived-summary envelope,
exact source citations and complete processing proof. Originals remain canonical
and retrievable; a selective summary never asserts that all original facts fit
inside it. This uses the existing progressive-summary principle: generated text
is derived context with source evidence, never new testimony or permissions.

The existing timeline B owner processes one bounded original window plus its
accepted prior working summary, using a bounded cold author_timeline request.
The summary is at most8192 UTF-8 bytes with at most16 cited items. Each citation
must match the current authorized window or an already accepted prior citation;
SQL independently verifies exact owner/source/version/spans. There is no model
call for an authorized reply_only work decision or a tombstone. There is no
organiser/composer invocation or new logical lane owner.

Summary cursor/revision and idempotent receipts belong to canonical compaction
maintenance, separate from composer cursors and completed rounds. Each quantum
is bounded and resumable. Canonical page digests bind the summary input and
provider admission, and current policy/source/lease checks fence commit.
Corrections revoke unfinished and published derived summaries. Only complete
coverage plus accepted summary processing can advance the existing checkpoint
head by predecessor CAS. A keeps its complete raw tail until publication.

Tests cover a large backlog, old violet-kite recall, K/tail/current bounds,
long Unicode windows, worker restart/replay/cancellation, stale CAS, policy/source/
lease/owner denial, bounded payloads, a real native HTTP continuation and flag
rollback. Controlled model outputs prove mechanics and provenance, not live
semantic retention/quality; live evaluation remains a separate gate.

A checkpoint head cannot move backwards when an older B snapshot finishes.
An older accepted-turn retry selects an accepted checkpoint strictly before its
original source, and pins that exact choice through preparation. A freshly
captured canonical execution fence permits the atomic retry to finish against
newer raw-source inventory without changing the original admission metadata.
The legacy entry points retain their source-snapshot staleness checks; the shared
validators retain source-version, policy, photo, news, phase and lease checks.

Semantic summary calls and every validation repair count against the existing
background call/token/cost ceiling in the frozen benchmark plan. A long backlog
may use one call per authorized 2,000-character window; each worker quantum is
bounded and checkpoints advance only after all required windows. This adds no
foreground classifier or second normal A call. Do not increase the540-call B
ceiling or start a funded campaign implicitly. A future authorized campaign must
freeze sufficient scenarios and budget before dispatch, or stop at that ceiling
and report unfinished B work. No live campaign was run here.
