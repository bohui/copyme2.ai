## Current-source change

The existing canonical checkpoint accepts either complete lossless evidence or
a bounded selective derived summary with exact original citations. The existing
coalesced timeline B owner processes every required source/tombstone/window with
separate durable summary cursors and idempotent receipts. It publishes by
predecessor CAS only after raw coverage and accepted processing are complete.
Each request contains at most one 2,000-character source window and an 8,192-byte,
16-item working summary. Originals remain canonical and retrievable. Summary
text is generated context, never new testimony or permission. No claim is made
that every original fact fits in the summary.

Older B results cannot rewind the canonical frontier. A pins its checkpoint and
complete tail before execution; a later optional checkpoint cannot replace that
choice during preparation. A technical retry of an old accepted input selects a
compatible checkpoint strictly before its source and uses the current execution
fence at atomic save. The original source identity/version/admission sequence
remain unchanged. Shared legacy validators retain their direct-call staleness
checks and existing source/policy/phase/photo/news/lease rules.

Routine B remains independent of A, retains bounded cold author_timeline
execution and the existing B capacity/quantum. Summary work never composes,
publishes a public draft, records a question asked, advances completed rounds or
grants access. All summary calls and repairs count against the existing B
benchmark ceiling; this work authorizes no extra funded calls.
