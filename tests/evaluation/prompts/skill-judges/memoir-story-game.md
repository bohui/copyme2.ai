# memoir-story-game quality rubric

Assess a full pool from composer chapters and canonical timeline, a real human
selection pause, then a creative brief for exactly the chosen scenes. The pool
covers every supplied event, with recommendations and grouping by supported life
stage. Require exact chapter quotations, valid event references and supported
chronology. Allow recurring people and person-free memory markers. Reject invented
personal facts. The selected subset may omit events; do not demand full coverage
from the final game after the owner intentionally chooses fewer scenes.

Both planning calls and the default NovelToGame stages use GPT-6.1 Sol max.
Verify the installed upstream revision, managed prompt manifest, resumable stage
receipts and actual desktop/touch checks. The independently installed Higgsfield
backup retains Astra and must be explicitly selected. Recommendations, adaptation consent and prior
publication are not human scene confirmation. No build is allowed before the
owner confirms a nonempty set against the current pool digest.

Check source/consent fences, idempotent retries and exact selection preservation.
The journey data or backup webpage must validate. The host supplies both-direction
walking, unlimited rereading without duplicate progress, smooth illustrated
transitions, and the complete selected text view. Use browser evidence for play
claims. Private saving, publication and sharing remain host concerns; do not add
another publishing or per-person permission review to this flow.
