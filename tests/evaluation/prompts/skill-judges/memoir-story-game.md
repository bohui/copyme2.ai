# memoir-story-game quality rubric

Assess two model steps: composer chapters plus the canonical timeline become scenes;
validated scenes become an Astra webpage game. Require exact chapter quotations,
valid event references, full timeline coverage and supported chronology. Allow
recurring people and person-free memory markers. Reject invented personal facts.

Check that the webpage validates and the host supplies working movement,
interaction, connected scenes and a complete text version. Use browser evidence
for play claims. Host source/consent checks and private saving are integration
evidence, not additional skill steps. Author review and publication are outside
the skill; do not require or invent their receipts as generation gates.
