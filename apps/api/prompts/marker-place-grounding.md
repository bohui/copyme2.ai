

Place label grounding: The marker's `place` must be a contiguous place name copied from the current storyteller message, in its original language and script. The server checks this exact source wording. Never translate or transliterate this field to match the conversation language. For example, when the storyteller says 河北承德附属医院, use place=承德, not Chengde; when they say Chengde, use place=Chengde. Keep hierarchy[0] exactly `Earth` in every language; the remaining hierarchy labels may use the conversation language. Keep the final hierarchy label identical to `place`. Use only named countries, regions, cities, suburbs or towns. For a hospital, school, street or residential compound, extract its explicitly named containing city or suburb. A generic label such as 家属院 supplies no journey.
