# Product brief — The Blue Gate, age eight

Mode: quick. targetFinish: playable-prototype. experienceProfile: hybrid.
Language: English (Australia). Source: the full fictional age-eight benchmark,
ten composer chapters and ten canonical timeline events.

## Locked experience

One continuous chronological RPG side-scrolling memoir path. Walk forward or
backward through the timeline's layout; preserve uncertain ordering within the
year. Approach any memory, pause to read, and revisit it as often as desired.
Read/Read again stays available after a visit and after completion. Count each
memory once, with no restriction on reading order or passing an unread marker.
Illustrations pan and blend between places with a stable ground/player baseline.
Later visits occur further along the stream. Keep progress, source view, ending
and restart. The host owns the runtime; models provide a validated route and style.

Target a 3–5 minute main route, with untimed optional reading and exploration.
Native offline HTML/CSS/JavaScript and system fonts. Use the supplied
`illustrated-lifetime-v1` avatar family, CSS markers and original opt-in
music. Generate only source-supported scene backgrounds in its illustrated
style; group compatible places into an atlas and reuse cached illustrations.
Select age/outfit variants from approved timeline and character metadata. The
age-eight source uses the child throughout; an activity is not a profession.
Keyboard movement/interaction and large touch buttons; clear focus, reduced
motion, readable text and responsive reflow from 320 CSS pixels. No network,
external libraries, accounts, storage, forms, publishing or runtime models.

## Fixed memoir facts

All ten chapters and linked timeline events inform the design. Every event has
an explicit playable or contextual treatment; the unchanged complete passages
remain accessible. Exploration order does not establish uncertain chronology.
The source bible is evidence, not permission to invent additional personal facts.

Historical outcomes stay fixed: the first remembered patch lifted, a later patch
stayed flat, the school-play line was eventually said, and the seedling opened
the next morning. Recovery of the dropped coin remains unknown. Retain reported
perspective, uncertain dates and uncertain remembered wording. Sam is a child
classmate; the full fictional source retains its permissions statement. Add no
real-person permissions decision. Keep private provenance outside the game.

## Handoffs and verification

Use the separate pinned upstream skills with the RPG adapter, one persisted
stage at a time. The earlier source analysis may be reused with its exact input
fingerprint and real receipt. Its repair-puzzle concept, design and QA are
historical and do not satisfy this RPG brief.

The user requested GPT-6.1 Sol max. Make live calls only when explicitly
executing an authorised stage. Keep requested output budgets in receipts and
report actual usage; do not promise a hard token ceiling. After a failed large
build, narrow the next pass to one file; use at most two repair passes per
candidate before recording the unresolved state.

Before art, verify actual movement, camera, scene transitions and interaction in
the whitebox. Final QA must prove launch, render, input, core loop, ending and
restart in one complete clean run, with desktop and phone coverage reported
honestly. Each new run starts with generation and QA NOT_RUN.

This package is an isolated evaluation. The active Memoir RPG/scroller workflow,
Higgsfield installation, managed prompts, Langfuse pins, authentication and saved
games remain unchanged.
